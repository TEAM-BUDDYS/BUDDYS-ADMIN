# BUDDYS-ADMIN

BUDDYS 운영자가 제출 서류를 확인하고 승인 또는 반려하는 관리자용 React SPA입니다.

## Quick Start

현재 Vite 버전과 호환되는 Node.js와 pnpm이 필요합니다.

```bash
pnpm install
pnpm dev
```

터미널에 출력된 로컬 URL에서 애플리케이션을 확인합니다. 자세한 실행 방법과 환경변수 기준은 [Local Development](./docs/workflows/local-development.md)를 참고합니다.
